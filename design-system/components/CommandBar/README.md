# CommandBar

Campo de comando no estilo do terminal: você escreve em português o que faria na conversa ("saldo de todas as contas", "pausar campanha X") e o assistente executa ou abre a tela certa.

- Prompt `›` em accent, texto em mono. Sugestões são chips clicáveis.
- Pedidos de edição sempre terminam num `ConfirmDialog`.
