# Button

Botão de ação. `primary` (verde accent) só para a ação principal da tela — normalmente "Revisar alteração" ou "Confirmar e aplicar"; `secondary` para o resto; `ghost` para ações de linha e cancelar; `danger` para pausar em massa ou remover.

- Rótulo no infinitivo: **Pausar**, **Ativar**, **Salvar orçamento**.
- Um `primary` por área. Tamanho `sm` dentro de tabelas e cards.
- Você fornece: `children` (rótulo), `onClick`, `variant`, `size`, `disabled`.
