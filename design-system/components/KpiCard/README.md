# KpiCard

Um número-chave com rótulo e variação. Valor em `metric` (mono), rótulo em `label`.

- `delta` em %, com sinal. `goodWhen="down"` para métricas em que cair é bom (CPA, CPM): a cor segue o resultado, não a direção.
- Use 3–4 por linha no topo das telas. Você fornece o valor já formatado (`R$ 12.480,90`).
