# AccountCard

Resumo de uma conta de anúncio do Meta: nome, ID `act_…`, status, saldo, gasto do dia, campanhas ativas e o resultado principal.

- Mostre `alert` quando o saldo cobre menos de 3 dias ou a conta está bloqueada — em `warn` ou, com `status="erro"`, em `danger`.
- Grade de cards na Visão geral; `onOpen` leva à tela da conta.
