# StatusBadge

Selo de status de conta, campanha ou anúncio, sempre com texto e ponto — nunca só cor.

| status | texto padrão | quando |
|---|---|---|
| `ativa` | Ativa | veiculando |
| `pausada` | Pausada | pausada manualmente |
| `revisao` | Em análise | anúncio em revisão do Meta |
| `alerta` | Saldo baixo | saldo abaixo do limite do alerta |
| `erro` | Sem saldo | conta parada, pagamento recusado ou anúncio reprovado (passe `children` com o motivo) |
