# Painel de Tráfego

- `painel/painel-trafego.html` — o painel funcionando (publicado como Artifact no claude.ai). Lê as contas de anúncio ao vivo pelo conector Criativivo e permite pausar/ativar campanhas e conjuntos e mudar orçamento diário, sempre com confirmação.
- `rastreamento/` — sistema próprio de rastreamento de leads de WhatsApp (Meta e Google). Veja `rastreamento/README.md`.
- `design-system/` — tokens, componentes e telas de referência do design system "Painel de Tráfego".
